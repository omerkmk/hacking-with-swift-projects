# Project 2 — Guess the Flag

Üç bayrak görseli gösterilir; başlıkta sorulan ülkenin bayrağına dokunmaya çalışırsın.

## Özellikler

- Rastgele üçlü ve doğru cevap konumu
- Skor ve 10 soruluk tur; doğru/yanlış uyarıları (`UIAlertController`)
- Bayrak görselleri `Assets` ve `Flags` klasöründe

## Çalıştırma

`Project2.xcodeproj` dosyasını Xcode’da açıp çalıştır.

## Konular

`UIButton`, `UIImage`, navigation item, alert
