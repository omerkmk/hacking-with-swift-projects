# Project 5 — Word Scramble

Başlıkta rastgele bir kelime gösterilir; harflerini kullanarak yeni geçerli kelimeler üretip listeye eklersin.

## Özellikler

- Kelime havuzu: `Project5/start.txt`
- `UITableView` ile bulunan kelimeler
- Metin girişi (`UIAlertController` + `UITextField`)
- Kontroller: mümkün mü, daha önce kullanıldı mı, en az 3 harf, sözlükte var mı (`UITextChecker`)

## Çalıştırma

`Project5.xcodeproj` dosyasını Xcode’da açıp çalıştır.

## Konular

String manipülasyonu, `Bundle` ile kaynak okuma, tablo veri kaynağı
