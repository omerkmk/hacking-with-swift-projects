# Project 6a — Guess the Flag (Auto Layout)

Kursun “Project 6” bölümünün storyboard / Auto Layout ayağı: yine bayrak tahmin oyunu, arayüz kısıtları Interface Builder üzerinden düzenlenir.

## Önemli

Xcode proje dosyası adı **`Project2.xcodeproj`**, kaynak klasörü **`Project2/`**. Bu, kursda aynı uygulamayı Auto Layout ile güncellerken yaygın bir düzen; repoda klasör adı `Project6a` olarak duruyor.

## Çalıştırma

`Project6a/Project2.xcodeproj` dosyasını aç (veya `Project6a` klasöründen Xcode ile bu dosyayı seç).

## Konular

Auto Layout, constraint’ler, farklı ekran boyutları
